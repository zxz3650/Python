# 04-5. CSV 읽기·검증·안전한 출력

CSV는 행과 열로 구성된 표 형식입니다. 값 안에 쉼표·줄바꿈·따옴표가 들어갈 수 있으므로 `split(",")` 대신 표준 `csv` 모듈을 사용합니다.

{% hint style="info" %}
## 🧭 학습 목표

- `csv.reader`와 `csv.DictReader`를 구분합니다.
- 문자열 필드를 필요한 자료형으로 변환합니다.
- 필수·중복 헤더와 누락·초과 열을 검증합니다.
- 오류 행의 위치와 원인을 기록합니다.
- `DictWriter`로 새로운 CSV를 작성합니다.
- 스프레드시트로 열 때의 수식 해석 위험을 설명합니다.
{% endhint %}

## 선행 지식

텍스트 파일과 리스트·딕셔너리를 이해해야 합니다.

## 1. CSV 읽기

```python
import csv
from pathlib import Path

path = Path("people.csv")

with path.open("r", encoding="utf-8", newline="") as file:
    reader = csv.reader(file)
    for row in reader:
        print(row)
```

각 행은 문자열 리스트로 반환됩니다. `newline=""`은 CSV 모듈이 줄바꿈을 직접 처리하도록 합니다.

## 2. DictReader

```python
records = []

with path.open("r", encoding="utf-8", newline="") as file:
    reader = csv.DictReader(file)
    for row in reader:
        records.append(row)

print(records[0]["name"])
```

헤더가 키가 되므로 각 필드의 의미를 이름으로 확인할 수 있습니다.

## 3. 자료형 변환과 검증

CSV에서 읽은 모든 필드는 기본적으로 문자열입니다.

```python
valid_records = []
errors = []

with path.open("r", encoding="utf-8", newline="") as file:
    reader = csv.DictReader(file, strict=True)

    required_fields = {"name", "age"}
    fieldnames = reader.fieldnames or []

    if len(fieldnames) != len(set(fieldnames)):
        raise ValueError("중복 CSV 헤더가 있습니다")

    missing_headers = required_fields - set(fieldnames)
    if missing_headers:
        raise ValueError(
            f"필수 헤더 누락: {sorted(missing_headers)}"
        )

    for line_number, row in enumerate(reader, start=2):
        try:
            if None in row:
                raise ValueError("헤더보다 값이 많은 행입니다")
            if any(value is None for value in row.values()):
                raise ValueError("필드가 누락된 행입니다")

            age = int(row["age"])
            if age < 0:
                raise ValueError("나이는 0 이상이어야 합니다")
        except (ValueError, TypeError, KeyError) as exc:
            errors.append({
                "line": line_number,
                "raw": row,
                "error": str(exc),
            })
            continue

        row["age"] = age
        valid_records.append(row)
```

헤더가 1행이므로 데이터 행 번호는 2부터 시작합니다.

`DictReader`는 헤더보다 값이 많은 행을 `None` 키에 모으고, 값이 부족한 행에는 `None`을 넣습니다. 자료형 변환 전에 행 구조부터 확인합니다.

## 4. 쉼표가 포함된 값

```python
from io import StringIO

text = 'name,note\nAlice,"Seoul, Korea"\n'
reader = csv.DictReader(StringIO(text))

print(next(reader))
```

CSV 모듈은 따옴표로 감싼 쉼표를 하나의 필드로 처리합니다.

## 5. CSV 쓰기

```python
fields = ["name", "age", "city"]

with Path("output.csv").open(
    "w",
    encoding="utf-8",
    newline="",
) as file:
    writer = csv.DictWriter(file, fieldnames=fields)
    writer.writeheader()
    writer.writerows(valid_records)
```

출력 열과 순서를 `fieldnames`로 명시합니다.

## 6. UTF-8 BOM

스프레드시트 프로그램과의 호환이 필요하면 `utf-8-sig`를 사용할 수 있습니다.

```python
with Path("excel_output.csv").open(
    "w",
    encoding="utf-8-sig",
    newline="",
) as file:
    writer = csv.DictWriter(file, fieldnames=fields)
    writer.writeheader()
    writer.writerows(valid_records)
```

## 7. 스프레드시트 수식 해석 주의

CSV 자체에는 실행 기능이 없지만 일부 스프레드시트는 `=`, `+`, `-`, `@`로 시작하는 셀을 수식으로 해석할 수 있습니다. 따옴표로 감싼 CSV 필드도 스프레드시트에서는 수식이 될 수 있습니다.

외부 입력을 사람이 스프레드시트에서 열 예정이라면 다음 정책을 정합니다.

- 수식이 필요 없는 텍스트 열은 허용 문자와 형식을 검증합니다.
- 수식 접두 문자로 시작하는 값은 경고하거나 별도 검토 대상으로 분리합니다.
- 숫자 열의 음수와 텍스트 열의 `-` 시작 값을 같은 규칙으로 처리하지 않습니다.
- 제품별 이스케이프 방식을 확인하지 않고 원본 데이터를 임의로 변경하지 않습니다.

```python
FORMULA_PREFIXES = ("=", "+", "-", "@")


def validate_spreadsheet_text(value):
    if value.lstrip().startswith(FORMULA_PREFIXES):
        raise ValueError("수식으로 해석될 수 있는 텍스트입니다")
    return value
```

위 함수는 수식이 허용되지 않는 **텍스트 필드**에만 적용합니다.

## 흔한 실수

- 쉼표로 직접 문자열을 분리함
- 숫자 필드를 문자열 상태로 계산함
- 헤더 누락을 확인하지 않음
- 중복 헤더와 누락·초과 열을 확인하지 않음
- 실제 파일 행 번호를 잘못 기록함
- `newline=""`을 생략함
- CSV 따옴표가 스프레드시트 수식 실행을 막는다고 생각함

{% hint style="success" %}
## 🧪 종합 실습

상품명·가격·수량 CSV를 읽고 헤더·행 구조·숫자 범위를 검증합니다. 정상 행에는 합계 금액을 추가해 새 CSV로 저장하고 오류 행은 별도로 보존합니다. 상품명은 수식으로 해석될 수 있는 접두 문자를 검사합니다.
{% endhint %}

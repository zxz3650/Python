# 13-1. 자동화 과제 선정과 안전 설계

자동화의 첫 단계는 코드가 아니라 작업의 경계를 정의하는 것입니다. 사람이 수행하는 절차를 입력, 규칙, 출력, 실패, 승인 단계로 나눈 후에 그 일부를 Python으로 옮깁니다.

{% hint style="info" %}
## 🧭 학습 목표

- 반복 작업을 자동화 후보로 평가합니다.
- 입력·변환·출력·증거의 흐름을 정의합니다.
- 미리보기, 멱등성, 원상복구, 최소 권한을 적용합니다.
- 성공을 출력 파일이 아니라 검증 규칙으로 판정합니다.
{% endhint %}

## 1. 좋은 자동화 후보

다음 질문에 대한 답이 많을수록 자동화 효과가 큽니다.

- 같은 절차를 자주 반복하는가?
- 입력과 결과의 형식이 일정한가?
- 규칙을 문장과 예시로 설명할 수 있는가?
- 실수가 자주 발생하지만 수정 규칙은 명확한가?
- 성공 여부를 건수, 합계, 해시, 상태 값으로 확인할 수 있는가?

반면 매번 판단 기준이 바뀌거나, 한 번의 실수가 회복하기 어려운 삭제·외부 전송·결제 작업은 완전 자동화보다 **초안 생성 + 사람 승인**에 적합합니다.

## 2. 작업 카드 작성

코딩 전에 다음 템플릿을 채웁니다.

| 항목 | 질문 | 예시 |
| --- | --- | --- |
| 트리거 | 언제 시작하는가? | 매주 월요일 09:00 |
| 입력 | 무엇을 읽는가? | `inbox/*.csv` |
| 규칙 | 어떻게 변환하는가? | 날짜·금액 검증 후 분류별 합계 |
| 출력 | 무엇을 만드는가? | `reports/weekly.xlsx` |
| 증거 | 무엇을 남기는가? | 처리·오류 건수, 입력 해시, JSON 로그 |
| 실패 | 어디서 중단하는가? | 필수 열 누락 시 출력 갱신 금지 |
| 재시도 | 무엇을 다시 해도 되는가? | HTTP 429·5xx만 제한적 재시도 |
| 승인 | 사람이 확인할 단계는? | 메일 전송 전 수신자·첨부파일 검토 |

## 3. 미리보기와 적용 분리

변경 계획을 만드는 함수와 실제로 변경하는 함수를 나눕니다.

```python
def build_plan(files, rules):
    """부작용 없이 변경 계획만 반환한다."""
    return [classify(path, rules) for path in files]


def apply_plan(plan, *, approved=False):
    if not approved:
        raise ValueError("명시적 승인이 필요합니다.")
    for operation in plan:
        execute(operation)
```

CLI에서는 `plan` 명령을 기본으로 하고, `apply`는 사용자가 직접 선택하게 합니다. 예상 변경 건수와 출발·도착 경로를 JSON이나 표로 보여 줍니다.

## 4. 멱등성과 중복 방지

멱등성은 같은 작업을 다시 요청해도 결과가 중복되거나 망가지지 않는 특성입니다.

- 출력 파일을 임시 경로에 완성한 후 `replace()`합니다.
- 처리한 입력의 해시나 작업 ID를 기록합니다.
- 도착 경로가 이미 있으면 덮어쓰지 않고 충돌 규칙을 적용합니다.
- 트리거가 중복되어도 같은 시간 구간의 작업은 한 번만 실행합니다.

```python
temporary = output.with_suffix(output.suffix + ".tmp")
temporary.write_text(payload, encoding="utf-8")
temporary.replace(output)
```

## 5. 원상복구 가능한 작업 기록

파일 이동처럼 되돌릴 수 있는 작업은 변경 전·후 정보를 모두 남깁니다.

```json
{
  "operation": "move",
  "source": "/lab/inbox/report.csv",
  "destination": "/lab/sorted/data/report.csv",
  "status": "applied"
}
```

작업 기록은 비밀값을 포함하지 않아야 하며, 파일 경로에 민감한 사용자 정보가 들어간다면 보관·접근 권한을 별도로 관리합니다.

## 6. 최소 권한과 경로 경계

자동화 프로그램은 필요한 폴더와 API에만 접근해야 합니다.

```python
root = Path(args.root).expanduser().resolve()
candidate = Path(args.input).expanduser().resolve()

if not candidate.is_relative_to(root):
    raise ValueError("허용된 작업 경로 밖입니다.")
```

- 가능하면 학습용 임시 폴더에서 먼저 실행합니다.
- 심볼릭 링크를 무조건 따라가지 않습니다.
- 관리자 권한으로 실행하기 전에 권한 없이 해결할 방법을 먼저 찾습니다.
- 삭제와 외부 전송은 자동 승인하지 않습니다.

## 7. 성공·실패 기준

`예외이 없었다`는 성공 기준이 아닙니다. 출력 계약을 검증합니다.

```python
assert processed + rejected == total
assert report_path.exists()
assert report_path.stat().st_size > 0
```

외부 서비스를 호출했다면 상태 코드뿐 아니라 응답 형식, 필수 필드, 처리 식별자를 확인합니다.

## 실습

반복 중인 업무 하나를 골라 작업 카드를 작성합니다.

1. 수작업 1회의 입력·순서·출력을 기록합니다.
2. 변하지 않는 규칙과 사람의 판단이 필요한 규칙을 나눕니다.
3. 잘못된 입력 3가지와 중단 기준을 정의합니다.
4. 미리보기에 표시할 정보를 정합니다.
5. 재실행과 원상복구 방법을 적습니다.

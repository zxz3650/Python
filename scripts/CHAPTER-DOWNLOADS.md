# 챕터별 배포본 관리

학습자는 각 장의 ZIP만 받는다. 원본 교안·코드·노트북은 기존 경로에서 관리하고, 배포본은 아래 명령으로 생성한다.

```bash
python scripts/build_chapter_downloads.py
python scripts/build_chapter_downloads.py --check
```

첫 명령은 01~13장의 현재 입력을 확인하고 내용이 달라진 ZIP과 목록만 갱신한다. 두 번째 명령은 파일을 쓰지 않고 배포본과 원본이 다른 경우 종료 코드 1로 알린다. 코드·노트북·fixture 수정 후에는 두 명령을 순서대로 실행하고, 변경된 원본과 downloads의 배포본을 같은 커밋에 포함한다.

- downloads/chapter-NN.zip: 교안에 연결하는 고정 다운로드 경로
- ZIP 내부 chapter-NN-자료버전/: 이전 개인 풀이와 구분되는 폴더
- START-HERE.md: 학생용 실행 안내와 시작 노트북 목록
- MANIFEST.json: 장 번호·자료 버전·포함 파일별 SHA256
- downloads/index.json: ZIP별 자료 버전·크기·SHA256
- downloads/README.md: 학생용 다운로드 목록

자료 버전은 해당 ZIP에 들어가는 파일 내용에서 계산한다. 빌드 시각이나 전체 저장소 커밋은 버전 입력으로 사용하지 않으므로, 다른 챕터 또는 온라인 교안 문구만 수정하면 이 장의 ZIP은 바뀌지 않는다. 동일한 실행 환경에서 같은 입력을 재빌드하면 ZIP 바이트도 같다. 패키지 설치 결과는 별도로 관리하며 자료 버전이 의존 패키지를 고정하지는 않는다.

포함 범위는 build_chapter_downloads.py의 EXTRA_PATHS에 명시한다. 현재 08장은 07장 로컬 서버 코드에 의존하므로 이를 같이 포함한다. 05장은 fixtures와 풀이 참고 노트북, 13장은 현재 KAPE 프로젝트와 검증 코드를 포함한다. 이전 교안 예제, 개인 작업 파일, 가상환경, 실행 결과는 배포하지 않는다.

새 의존성을 추가할 때는 ZIP을 저장소 밖 임시 폴더에 풀고, 그 안의 notebooks 폴더에서 실행해 경로를 확인한다. 05장 학습자용 TODO 파일은 검증 실패가 예상되므로 시작 셀의 데이터 접근과 별도 풀이 검증을 구분한다.

GitHub에 푸시하기 전에는 새 ZIP의 원격 다운로드 링크가 동작하지 않는다. 위 두 명령은 Git 커밋·푸시·GitBook 게시를 수행하지 않는다.

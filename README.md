## 과정 설계 원칙

- 문법과 프로그래밍 기반을 먼저 학습합니다.
- 파일·데이터·네트워크·HTTP·운영체제 순서로 적용 범위를 확장합니다.
- 각 장은 개념, 최소 예제, 실패 사례, 종합 실습, 완료 기준 순서로 구성합니다.
- 실습은 소유하거나 명시적으로 허가받은 환경에서만 수행합니다.

## 13. Python Automate 실무 자동화

[13장 교안](13-python-automate.md)은 KAPE 결과와 Windows 아티팩트를 통합하는 오프라인 분석 프로젝트로 진행합니다.

- 수집 자료·파서 출력의 목록과 원본 해시 관리
- CSV 열 매핑, UTC·시각 의미 정규화, 입력 오류·미수집 자료 구분
- 이벤트·Prefetch·레지스트리·MFT 등 관련 근거 조회
- 다중 호스트 타임라인, 교육용 검토 규칙, HTML·JSON 보고서
- 외부 엔진·워커 연계는 기본 파이프라인 이후 확장 과정으로 학습

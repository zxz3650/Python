# 06-5. UDP 통신

UDP는 연결 수립 없이 독립된 데이터그램을 전송합니다. 메시지 경계를 보존하지만 전달·순서·중복 방지를 보장하지 않습니다.

{% hint style="info" %}
## 🧭 학습 목표

- TCP와 UDP의 보장 범위를 비교합니다.
- `sendto()`와 `recvfrom()`으로 데이터그램을 송수신합니다.
- UDP 서버를 로컬 주소에 바인딩합니다.
- 손실·중복·순서 변경 가능성을 설명합니다.
{% endhint %}

## 1. TCP와 UDP 비교

| 항목 | TCP | UDP |
| --- | --- | --- |
| 연결 | 연결 수립 | 연결 없이 전송 가능 |
| 데이터 형태 | 바이트 스트림 | 데이터그램 |
| 순서 | 보장 | 보장하지 않음 |
| 재전송 | 프로토콜이 처리 | 애플리케이션 책임 |
| 메시지 경계 | 보존하지 않음 | 보존 |

## 2. UDP 서버

```python
import socket

HOST = "127.0.0.1"
PORT = 9001

with socket.socket(socket.AF_INET, socket.SOCK_DGRAM) as server:
    server.bind((HOST, PORT))
    server.settimeout(10.0)

    data, address = server.recvfrom(4096)
    server.sendto(data, address)
```

`recvfrom()`은 데이터와 송신자 주소를 함께 반환합니다.

## 3. UDP 클라이언트

```python
with socket.socket(socket.AF_INET, socket.SOCK_DGRAM) as client:
    client.settimeout(3.0)
    client.sendto(
        "hello".encode("utf-8"),
        (HOST, PORT),
    )

    response, server_address = client.recvfrom(4096)

print(response.decode("utf-8"))
```

## 4. 응답 검증

UDP는 위조된 출발지나 예상하지 않은 응답을 고려해야 합니다. 학습 예제에서도 응답 주소와 데이터 형식을 확인합니다.

```python
if server_address != (HOST, PORT):
    raise ValueError("예상하지 않은 서버 주소입니다")
```

호스트 이름을 사용하면 실제 응답 주소가 달라질 수 있으므로 주소 해석 결과를 기준으로 검증해야 합니다.

## 5. UDP에서 재시도할 때

재시도를 추가하면 중복 요청이 발생할 수 있습니다. 요청 ID를 포함하고 서버가 같은 ID의 요청을 어떻게 처리할지 정의해야 합니다.

```python
request = {
    "request_id": "training-001",
    "message": "hello",
}
```
